## 🧠 Overview

Oniric is a Photoshop plug-in for glow and light bleed: it builds a separate glow layer from the highlights of the image, with controls for threshold, radius and colour, so the effect can be blended or masked afterwards.

On a Windows machine it runs as a plug-in suite that loads inside Adobe Photoshop CC 2019 or newer. Typical use is glow generation for photoshop work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| ✨ Highlight Glow | Generates the glow only from pixels above a chosen brightness threshold. |
| 🎚️ Radius and Spread | Controls how far the light bleeds and how quickly it falls off. |
| 🌈 Colour Tint | Shifts the glow colour or keeps it neutral to the source. |
| 🧱 Separate Layer | The effect arrives on its own layer with a blend mode already applied. |
| 🎭 Mask Support | A selection or mask limits the glow to a region of the frame. |
| 🔁 Re-editable Settings | The plug-in can be reopened on the generated layer to change the parameters. |
